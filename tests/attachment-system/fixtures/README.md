# Pre-2.0 save fixtures

These are frozen `TreeAttribute` payloads generated by the compiled `v1.7.9` assembly (commit `61fe786`),
using its real `ItemImmersiveBag.Store` and `BlockEntityImmersiveBackpack.ToTreeAttributes` methods.

They are a permanent compatibility contract. Do not regenerate, replace, or remove them as part of a schema
change. Compatibility may be dropped only through an explicit project decision.

- `pre-2.0-held-backpack.tree.b64`: `placed_addons` plus flattened `backpack.slots`.
- `pre-2.0-placed-backpack.tree.b64`: block-entity metadata, `placed_addons`, and `InventoryGeneric` cargo.

Both fixtures contain per-stack attributes to detect silent attachment-state loss.
